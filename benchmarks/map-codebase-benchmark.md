## What this report shows

This is reproducible evidence for map-codebase's phase-one resolver on three original, executable reference projects: Atlas (billing), Northstar (developer portal), and SignalForge (telemetry). Each project has 18 evaluated tasks. `resolver-scale-stress` is a separate synthetic 3k-file workload used only for latency and bounded-candidate checks.

All three conditions receive the same prompt and repository state. The resolver uses its repository map and phase-one evidence; ripgrep is an independent lexical search baseline; inventory ranks the eligible tracked-file inventory. These are same-corpus controls, not comparisons with earlier fixture cohorts.

Token counts use the repository's offline `cl100k_base` implementation. Incorrect results receive no credited efficiency claim.

### Reading the results

- **Hit@1 / Hit@3**: whether a correct primary owner appears first or within the first three targets.
- **MRR**: rewards placing the first correct owner earlier in the ranked list (1.0 is best).
- **Macro role F1**: balanced correctness of source, test, and configuration roles.
- **Owner precision / recall**: how often named owners are right, and how often required owners are found.
- **Tokens**: context delivered to the condition; lower is useful only when the result is correct.

## How testing works

Fixtures are generated from committed blueprints, materialized into isolated repositories, and verified against canonical file and tree hashes. Prompts and expected ownership live in external hash-bound oracle bundles. The suite tests direct ownership, configuration, impact, abstention, generated and legacy decoys, prompt injection, dirty worktrees, and stale indexes. Fixture CI runs native behavior tests; source-text or file-existence placeholder tests are rejected.

Utility and scale timing are measured separately. Both require phase-one P95 below two seconds; utility projects also require build median below 30 seconds and refresh median below 15 seconds. The current release status is **pass**.
