# map-codebase 2.4.2: resolver-first navigation guidance in agent documents

`map-codebase` 2.4.2 updates the generated `## Repository Knowledge` receipt in `AGENTS.md` and `CLAUDE.md` to explicitly direct agents to navigate generated knowledge through the `map-codebase` resolver: start at phase 1 for the current task, read only returned targets and selected symbol shards, expand only when the current phase stop condition is unmet, and verify conclusions in current source. The static `KNOWLEDGE.md` workflow guide names the resolver consistently. The receipt stays markerless, idempotent, opt-out honoring, and atomic; no resolver, ranking, phase, fallback, or schema behavior changes.
