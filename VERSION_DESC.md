# ideate 2.0.0: contract v2 for support basis, adversarial review, and criteria linkage

`ideate` 2.0.0 introduces receipt/contract version 2 for `ideas.md`. Every candidate now declares an explicit `- Support basis:` (`evidence-backed`, `assumption-backed`, or `hypothesis`), optional contextual evidence (`C1..` IDs), per-candidate `- Decision-criteria fit:`, recommendation `- How decision criteria were applied:`, four required adversarial bullets in Section 6, and handoff research-stop fields. The comparison table uses `Support strength`; provisional-lead matching requires the exact rank-1 candidate ID (fixing `I1`/`I10` confusion). Deterministic validation enforces syntax and state coherence without judging semantic idea quality; agent obligations are documented separately. Offline structural fixtures span engineering, scientific, operations, and creative domains.
