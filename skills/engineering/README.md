# Engineering Skills Domain

This directory contains all canonical engineering skills.

## Workflows

| Skill | Status | Invocation | Summary |
| --- | --- | --- | --- |
| [plan-change](./plan-change/SKILL.md) | `stable` | `both` | Turn a feature, bug fix, refactor, migration, public contract, or risky integration into a repository-grounded, decision-complete implementation blueprint. |
| [implement-plan](./implement-plan/SKILL.md) | `stable` | `both` | Execute an approved implementation plan as the smallest complete patch — preserving existing patterns and uncommitted work, with layered verification and an exact change report. |
| [scope-issue](./scope-issue/SKILL.md) | `stable` | `both` | Ground one selected GitHub issue and seal `issue-handoff.md` for plan-change. |
| [audit-codebase](./audit-codebase/SKILL.md) | `stable` | `both` | Audit broadly and seal confirmed findings in `audit-handoff.md` for one-finding-at-a-time planning or explicit publication. |
| [diagram-codebase](./diagram-codebase/SKILL.md) | `stable` | `both` | Create self-contained HTML diagrams of systems, architectures, workflows, and code relationships. |

## Disciplines

| Skill | Status | Invocation | Summary |
| --- | --- | --- | --- |
| [design-codebase](./design-codebase/SKILL.md) | `stable` | `both` | Decide and justify a repository-grounded design, then seal `design-handoff.md` for plan-change. |
| [optimize-codebase](./optimize-codebase/SKILL.md) | `stable` | `both` | Compare evidence-backed optimization candidates and seal `optimization-handoff.md` for plan-change without patching. |
